# INTENT — youtube-kit

## 1. 이 프로젝트는 무엇을 하는가

YouTube 영상 URL에서 영상 정보, 자막, 미디어를 얻고, 재생목록 URL에서 재생목록 정보와
영상 목록을 얻는다. 여러 영상에 대한 작업을 한 번에 요청할 수도 있다.

쓰는 방법은 두 가지다.

- **함수·API** — 주피터 노트북 같은 파이썬 환경에서 직접 불러 쓴다.
- **CLI** — 다른 프로젝트나 도구가 명령으로 불러 쓴다.

## 2. 왜 이것을 원하는가

같은 기능이 두 자리에서 필요하다. 노트북에서 직접 다루며 결과를 확인하고 싶을 때가
있고, 다른 프로젝트나 도구가 명령으로 불러 파이프라인의 한 단계로 쓰고 싶을 때가 있다.

## 3. 변하지 않는 원칙

- **함수·API와 CLI가 모두 1급 사용 방법이다.** 어느 한쪽이 다른 쪽을 쓰기 위한
  부속으로 밀려나지 않는다.
- **판단하지 않고 주어진 조건대로 수행한다.** 영상·음성·자막에 대한 정보를 제공하고,
  무엇을 받을지는 사용자나 호출하는 프로그램이 정한다. 대체·우선순위·품질 선택을 하지
  않으며, 요청한 것이 없으면 다른 것으로 대신하지 않는다.

## 4. 다루지 않는 것

- **음성 전사.** 말소리를 글자로 바꾸는 일은 호출하는 쪽이 한다.
- **변환과 정리.** 받은 자막·음성·동영상의 형식을 바꾸거나 내용을 정리하지 않는다.
  받은 그대로 둔다.
- **자동 선택과 대체.** 품질을 골라 주거나 추천하지 않고, 없는 것을 다른 것으로
  대신하지 않는다.
- **숨은 보관.** 사용자가 모르는 곳에 결과를 따로 보관해 두고 꺼내 쓰지 않는다.
- **재생목록 통째로 받기.** 재생목록의 영상마다 조건을 대신 정해 한꺼번에 받지 않는다.
